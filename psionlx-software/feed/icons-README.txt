ICONS
=====

The pictures "Find new software" shows beside each package, 48 x 48 pixels,
named after the package: each program's own launcher icon, and for "Find new
software" itself, the icon Psion drew in 2005 for the TASKS entry it never
finished.

Made by mkfeed.py from the packages themselves; there is nothing here that is
not also inside the matching .ipk file.
